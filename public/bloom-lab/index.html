About this sound & the hardware controls

The first six chords reproduce the reel's notes. Each of the four new chord families has open or character, close, wide, and low voicings. They use the same five-voice engine and have their own just-intonation targets. Original reel mode starts these new chords with pure sine notes; Bloom adds moving harmonics. Choose Sine, Triangle, Saw, or Square for another base waveform. Set Bloom amount to zero to hear the base wave alone. The Harmonic count control sets the bloom's range; the base wave uses up to 24 harmonics, with high harmonics removed as pitch rises. Original overtones applies only to reel chords in Original reel mode. Waveforms share the same fundamental level, so brighter shapes may sound louder.

Spatial movement pans each complete voice at a different rate. The default uses the same harmonic levels, motion depths, and cycles as your combined audition, running continuously. This is an experimental browser instrument, not the installed Legio firmware. A gentle output compressor catches peaks.

Current hardware: Ceiling = pitch; Room = detuning; Color turn = octave variation; press + turn = chord; Tilt = original / saw / square; Cut = octave; Color CV = waveform morph. The controls here explore a future bloom engine, so they are intentionally more extensive.
